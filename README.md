# Godot Learning

This repository contains several small Godot projects used for learning and practice.

## Projects

- `godot-learning/` - Basic Godot learning project.
- `coin-dash/` - Coin Dash project.
- `dodge-the-creeps-2d/` - 2D Dodge the Creeps project.
- `space-rocks/` - Space Rocks project.
- `squash_the_creeps_start_1.1.0/` - Squash the Creeps 3D project.

## Opening a Project

Open Godot, choose **Import**, and select the `project.godot` file inside the project directory you want to run.

Most projects in this repository are configured for Godot 4.6.

## Notes

Generated editor data and local machine files should not be committed.
